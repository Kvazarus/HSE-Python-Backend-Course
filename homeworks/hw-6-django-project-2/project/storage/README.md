# Инструкция по применению миграций

Все команды выполняются из корня проекта через утилиту Make:

1. **Запуск базы данных:**
   `make db-up`
2. **Создание новых миграций** (если были изменены модели в `models.py`):
   `make migrations`
3. **Применение миграций и загрузка мок-данных:**
   `make migrate`
4. **Остановка базы и полное удаление данных (сброс):**
   `docker-compose -f storage/docker-compose.yml down -v`
